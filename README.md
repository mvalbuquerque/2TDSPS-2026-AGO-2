# 2TDSPS-2026-AGO-2

Repositório da turma **2TDS-PS-2026-AGO-2** — desenvolvido em Flutter.

## Sobre

Este repositório contém os materiais, exercícios e projetos desenvolvidos pela turma 2TDS-PS-2026-AGO-2.

## Tecnologia

- [Flutter](https://flutter.dev/) — SDK de UI multiplataforma desenvolvido pelo Google.
- [Dart](https://dart.dev/) — Linguagem de programação utilizada pelo Flutter.

## Como começar

1. Instale o Flutter seguindo a [documentação oficial](https://docs.flutter.dev/get-started/install).
2. Clone este repositório:
   ```bash
   git clone https://github.com/mvalbuquerque/2TDSPS-2026-AGO-2.git
   ```
3. Navegue até o diretório do projeto desejado e execute:
   ```bash
   flutter pub get
   flutter run
   ```
