1Objetivo da aula

Nesta aula você vai declarar variáveis com tipos explícitos e com var, entender quando usar final e const, formatar textos com interpolação de string e converter valores entre String, int e double.

2O que vamos aprender

var

Variável cujo tipo é inferido a partir do valor inicial atribuído. O tipo fica fixo depois disso.

final

Recebe um valor uma única vez. Use quando o dado não muda durante a execução (nome, curso).

const

Constante conhecida em tempo de compilação. Mais restritiva que final: o valor já precisa ser conhecido antes do programa rodar.

int · double · String · bool

Os tipos básicos: números inteiros, números com casas decimais, texto e valores verdadeiro/falso.

'texto $var'

Interpolação de string: insere o valor de uma variável dentro de um texto sem concatenar com +.

'${expr}'

Quando a interpolação envolve uma expressão ou chamada de método, envolva com chaves.

int.parse / double.parse

Convertem uma String em número. Lançam FormatException se o texto não for válido.

toStringAsFixed(2)

Formata um double com um número fixo de casas decimais, útil para valores monetários.

String?

Tipo anulável: aceita um valor do tipo declarado ou null. Sem o ?, Dart não permite null.

3Exemplo comentado

// Exemplo: declarar variáveis com tipos diferentes, usar interpolação
// e distinguir 'var' (mutável), 'final' e 'const' (imutáveis).
void main() {
  // 'var' porque o nome poderia ser reatribuído mais adiante.
  var nome = 'Vinny';
  // Tipos explícitos deixam claro o que cada variável armazena.
  int idade = 40;
  double altura = 1.69;
  bool alunoAtivo = true;

  // 'final' porque o curso não muda depois de definido.
  final curso = 'Dart/Flutter';
  // 'const' porque a carga horária é uma constante conhecida em tempo de compilação.
  const cargaHoraria = 80;

  // Reatribuição possível porque 'idade' foi declarada com tipo explícito (mutável).
  idade = idade + 1;

  print('Nome: $nome');
  print('Idade: $idade');
  // toStringAsFixed(2) formata o double com duas casas decimais.
  print('Altura: ${altura.toStringAsFixed(2)}');
  print('Aluno ativo: $alunoAtivo');
  print('Curso: $curso | Carga horária: $cargaHoraria h');
}

4Saída esperada

Nome: Vinny
Idade: 41
Altura: 1.69
Aluno ativo: true
Curso: Dart/Flutter | Carga horária: 80 h
